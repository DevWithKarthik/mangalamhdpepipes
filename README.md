# 🚀 Mangalam HDPE Responsive Website

A fully responsive industrial product showcase website built from a Figma design using HTML, CSS, and JavaScript.

This project focuses on creating a modern, interactive, and responsive user experience across desktop, tablet, and mobile devices.

---

## 🌐 Live Features

- Responsive layout for all screen sizes
- Sticky navigation bar
- Smooth scrolling navigation
- Interactive FAQ accordion
- Application slider with controls
- Dynamic manufacturing process section
- Infinite testimonial scrolling
- Product portfolio showcase
- Download resources section
- Contact form section
- Fully responsive footer
- Hover animations and UI interactions

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Font Awesome

---

## 📱 Responsive Breakpoints

Optimized for:

- 1024px
- 992px
- 768px
- 425px
- 320px
